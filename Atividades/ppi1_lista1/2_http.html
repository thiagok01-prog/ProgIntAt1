O HTTP (HyperText Transfer Protocol) é o protocolo de comunicação fundamental usado para transferir dados e carregar páginas web na World Wide Web.

Ele é usado na web atravéz de requisições e respostas, onde o navegador pede um recurso ao servidor, e o servidor processa a informação e devolve uma resposta ao navegador.

Request: a mensagem de request tem um HTTP, a URL e cabeçalhos com detalhes técnicos.

Response: A resposta inclui um código de três digitos, por exemplo 404 sendo o código de página não encontrada, e Response também recebe qual o conteúdo solicitado, que pode ser código HTML, imagens, vídeos ou arquivos JSON.
